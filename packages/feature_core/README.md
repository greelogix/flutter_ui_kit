# flutter_feature_kit_core

Core library for [Flutter Feature Kit](https://github.com/greelogix/flutter_ui_kit): YAML configuration, template rendering, feature and artifact generation.

## Usage

See the [repository README](https://github.com/greelogix/flutter_ui_kit) and `example/example.dart`.

```dart
import 'package:flutter_feature_kit_core/feature_core.dart';
```
