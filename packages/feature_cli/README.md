# feature_cli

Command-line tool for [Flutter Feature Kit](https://github.com/greelogix/flutter_feature_kit).

## Install

```bash
dart pub global activate feature_cli
```

## Commands (v0.2)

- `feature init`
- `feature create <name>`
- `feature add screen|model|repository|usecase <name> --feature <feature>`
- `feature doctor`
